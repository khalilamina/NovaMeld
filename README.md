# NovaMeld

NovaMeld is a Distributed Real-time Data Processing System that leverages Auto-scaling Framework capabilities.

NovaMeld is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- NovaMeld is a Distributed Real-time
- Data Processing System that leverages
- Auto-scaling Framework capabilities

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NovaMeld.git`
2. `cd NovaMeld`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
